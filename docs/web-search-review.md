# 웹 검색 도구(paas-web) — 운영 전 보안·비용 검증

웹 검색 MCP 서버(`/mcp/web`, `app/services/websearch.py`)는 **검증을 마친 출처만** 운영에 들어간다.
키를 넣어도 `PAAS_SEARCH_APPROVED`에 그 출처 id가 없으면 쓰지 않는다(목록에는 `state: pending`으로 보인다).
출처마다 비용 구조가 달라 승인도 출처 단위로 한다.

| id | 출처 | 키 설정 | 비용(2026-11 확인) |
|---|---|---|---|
| `global` | Brave Search API(전 세계) | `PAAS_SEARCH_BRAVE_KEY` | 매달 $5 무료 크레딧(약 1,000번), 넘으면 $5/1,000번 |
| `japan` | Brave 일본 지역 | `PAAS_SEARCH_BRAVE_KEY` | `global`과 같은 계정·크레딧을 나눠 쓴다 |
| `naver` | Naver 검색 API(웹 문서) | `PAAS_SEARCH_NAVER_ID`·`_SECRET` | 무료, 하루 25,000번(검색 API 전체) |
| `naver_news` | Naver 검색 API(뉴스) | 위와 같음 | 위와 같은 한도를 나눠 쓴다 |
| `baidu` | 百度千帆 AI 검색 | `PAAS_SEARCH_BAIDU_KEY` | 확인하지 못함 — 검증 때 확인 |

참고: Google Custom Search JSON API는 새 고객을 받지 않고 2027-01-01에 끝난다. Bing Search API는 2025-08-11에
끝났다. 야후 재팬은 공식 웹 검색 API가 없다(화면을 긁는 것은 약관 위반이라 하지 않는다).

## 보안 검증

- [ ] **검색어 유출** — 검색어는 그 회사 서버로 나간다. 사내 비밀(고객 정보·미공개 계획·내부 코드명)이 검색어로
      나갈 수 있는 경로를 확인한다. 지금 막는 것: 스마트워크 대화·통합 서버 묶음에 넣지 않았다(별도 MCP 서버를
      도구로 등록·바인딩한 곳만), 도구 설명에 「사내 비밀을 넣지 말라」를 적었다. 그것으로 충분한지, 검색어 사전
      검사(사내 용어·개인정보 패턴)가 필요한지 정한다.
- [ ] **제공사의 데이터 처리** — 각 제공사 약관·개인정보 처리방침에서 검색어 보관 기간, 학습·광고 이용 여부, 처리
      국가를 확인한다(특히 중국 소재 Baidu). 사내 보안 정책(해외 전송·중국 서비스)과 맞는지 보안 담당 확인.
- [ ] **키 보관** — 키는 서버 `.env`에만 둔다(콘솔·로그·감사에 남지 않는다 — 코드가 싣지 않는다). 키를 가진
      계정은 부서 공용 계정으로, 담당자 변경 시 넘겨줄 수 있게.
- [ ] **누가 쓰나** — 서버는 MCP 토큰·API 키로만 열린다. 도구로 등록해 어느 과제·앱에 바인딩할지, 바인딩한
      앱의 사용자가 누구인지 확인한다.
- [ ] **기록** — 감사에는 출처·검색어 길이·결과 수만 남는다(검색어 자체는 남기지 않는다). 사고 대응에 검색어가
      필요하다면 남기는 정책을 따로 정한다.
- [ ] **응답의 신뢰** — 결과(제목·요약·주소)는 외부 글이다. LLM이 결과 속 지시문을 따르지 않게 프롬프트에서 다룬다.

## 비용 검증

- [ ] **무료 한도와 과금 방식** — 위 표를 가입 화면에서 다시 확인한다(바뀔 수 있다). 결제 수단을 등록해야 하는지,
      한도를 넘으면 막히는지·과금되는지.
- [ ] **지출 상한** — 과금되는 출처(Brave 등)는 제공사 콘솔에서 월 지출 상한·알림을 건다. 상한이 없으면 무료
      크레딧만 쓰도록 결제 수단을 등록하지 않는 방법도 있다.
- [ ] **예상 사용량** — 서버 상한은 부르는 사람마다 한 시간 `PAAS_SEARCH_MAX_PER_HOUR`(기본 60번)이다. 바인딩할
      앱 수 × 사용자 수로 월 호출 수를 어림해 무료 한도와 견준다. 필요하면 상한을 낮춘다.
- [ ] **실측** — 키를 넣고 출처마다 몇 번 검색해 응답·과금이 예상대로인지 제공사 대시보드로 확인한다(이때는
      잠시 승인 목록에 넣고 시험한 뒤 판단).

## 승인

검증을 마친 출처 id를 서버 `.env`에 적고 다시 시작한다.

```
PAAS_SEARCH_APPROVED=naver,naver_news
```

승인한 출처가 하나라도 있으면 MCP 서버 목록에 `paas-web`이 올라온다. 승인을 거두려면 목록에서 빼고 다시 시작한다.
