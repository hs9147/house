# 웹 페이지 읽기 도구(paas-browser) — 운영 전 보안·비용 검증

웹 페이지 읽기 MCP 서버(`/mcp/browser`, `app/services/webbrowse.py`)는 서버 브라우저(Playwright)로 화면을 그려
제목·본문(마크다운)·링크를 돌려준다. **읽기만 한다**(누르기·입력·로그인 없음). 열 호스트를 정하고
(`PAAS_BROWSER_ALLOWED_HOSTS`) 검증을 마쳐 `PAAS_BROWSER_APPROVED=true`로 켜야 운영에 들어간다. 그 전에는
MCP 서버 목록에 나오지 않고, 불러도 「검증 전」으로 거절한다.

Playwright MCP(Node)를 그대로 붙이지 않은 까닭: 그것은 아무 사이트에서나 누르고 입력하는 도구라 사내망 안의
서버에서 쓰기에 범위가 너무 넓고, Node 서버를 따로 띄워 관리해야 한다. 같은 Playwright로 읽기만 하게 좁혔다.

## 보안 검증

- [ ] **사내망 통로(SSRF)** — 서버는 사내망 안에 있다. 허용 목록 밖의 호스트는 주소로도, 화면이 부르는 자원
      (스크립트·그림·리다이렉트·틀)으로도 열지 않는다(테스트: `tests/test_infosource_browser.py`). 허용 목록에
      사내 시스템(관리 화면·인증 서버)이 들어가지 않게 목록을 정한다. 하위 도메인이 함께 열리므로 `lge.com` 같은
      넓은 이름은 넣지 않는다.
- [ ] **로그인한 화면** — 쿠키·헤더를 싣지 않으므로 로그인해야 보이는 화면은 못 본다. 이것을 넘어서는 일
      (서버에 사용자 세션 저장)은 이 도구 범위 밖이다.
- [ ] **누가 쓰나** — 서버는 MCP 토큰·API 키로만 열린다. 통합 서버 묶음·스마트워크 대화에는 넣지 않았다(도구로
      등록·바인딩한 곳만). 어느 과제·앱에 바인딩할지 정한다.
- [ ] **기록** — 감사에는 호스트·읽은 글자 수·응답 코드·막은 자원 수만 남는다(주소의 경로·본문은 남기지 않는다).
- [ ] **응답의 신뢰** — 읽은 본문은 외부 글이다. LLM이 본문 속 지시문을 따르지 않게 프롬프트에서 다룬다.
- [ ] **약관** — 허용할 사이트의 이용 약관이 자동 수집을 금하지 않는지 확인한다.

## 비용 검증

- [ ] **서버 부하** — 한 번 열 때마다 브라우저를 띄운다(수 초, 수백 MB). 동시에 둘까지만 열고, 부르는 사람마다
      한 시간 `PAAS_BROWSER_MAX_PER_HOUR`(기본 30번)이다. 백엔드 한 인스턴스가 함께 감당하는지 대시보드
      「시스템 상태」의 메모리·요청 스레드로 확인한다.
- [ ] **LLM 토큰** — 본문은 2만 자에서 자른다. 바인딩한 앱의 대화가 페이지를 여러 장 읽으면 토큰이 는다.
- [ ] **외부 비용** — 없다(제공사 API를 쓰지 않는다).

## 승인

```
PAAS_BROWSER_ALLOWED_HOSTS=www.lge.co.kr,data.go.kr
PAAS_BROWSER_APPROVED=true
```

서버 `.env`에 적고 다시 시작한다. 승인을 거두려면 `PAAS_BROWSER_APPROVED=false`로 바꾸고 다시 시작한다.
